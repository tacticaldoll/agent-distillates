# 術語治理與可逆投影：系列地圖

## 系列邊界

本系列處理的是術語如何從生成式候選值變成可信、可維護、可回滾的共享知識。它不把術語污染歸因於「模型會犯錯」這個單一原因，而是追問：一個粗糙詞彙如何被永久化，為何精確只能事後驗證，以及什麼樣的投影、剝除、契約與分類制度能讓延後策展變得安全。

核心問題鏈如下：

```mermaid
flowchart LR
    A[生成式候選術語] --> B[固有熵與局部視角]
    B --> C[弱閘門與即時永久化]
    C --> D[術語污染棘輪]
    D --> E[延後策展需求]
    E --> F[穩定鍵與可逆投影]
    F --> G[對稱剝除與冪等重貼]
    G --> H[依角色、歸屬與時機治理]
```

本系列的邊界是術語污染、精確性成熟、穩定鍵、顯示值、錨點、重貼、對稱剝除、角色判定、知識歸屬與契約優先順序。它不展開一般語意污染分類，不討論完整規格驅動開發流程，也不把所有流程治理或分散式系統 correctness pattern 納入；那些問題只在它們支撐術語生命週期時就地使用。

## 概念槽位與角色

本系列最後形成一篇主報告，因為所有材料都服務同一條因果鏈：術語不能在生成當下被信任，卻可以透過可逆的產物投影與明確的生命週期治理，在事後變得可信。若拆成多篇，讀者會先看到各種局部戒律，卻延後看到它們其實都在保護同一件事：讓詞彙在尚未成熟時保持可撤回，在成熟後才成為共享契約。

| 槽位 | 核心功能 | 決策 |
| :--- | :--- | :--- |
| 污染乘積 | 說明污染不是固有熵本身，而是固有熵穿過弱閘門、自動晉升與持久化後形成的棘輪。 | 保留為主報告起點，建立「噪音可存在，但不能自動永久化」的問題框架。 |
| 精確的事後性 | 說明正規形式、邊界、變體調和與粒度都需要跨語料與跨時間證據。 | 保留為延後策展的理論理由。 |
| 可逆投影 | 說明穩定鍵、顯示值、錨點與重貼如何把產物從凍結快照改造成可重算投影。 | 保留為主報告核心機制，並以 Mermaid 補成基礎模型。 |
| 對稱剝除 | 說明重貼之前必須用同一把鍵拆乾淨；冪等無變更不等於正確。 | 保留為可逆投影的必要前置，不拆成獨立技術 note。 |
| 角色而非外形 | 說明外形、成員資格、語法類別只是代理，不能取代語意角色。 | 保留為管線設計戒律，連接剝除與跨階段訊號傳遞。 |
| 知識歸屬 | 說明流程可以捕捉知識，但不擁有知識；術語與規則應依解決的問題歸類。 | 保留為術語分類與去污染決策的治理層。 |
| 契約優先 | 說明先修正會被後續能力繼承的契約，再擴充能力。 | 保留為術語制度演進時的排序原則。 |
| 角色、歸屬與時機 | 說明相似物是否該拆開，取決於它們是否在不同時程上變動、被擁有或固化。 | 保留為結論性判準，支撐術語生命週期與規則放置。 |

## 合併、移出與保留決策

本系列只需要一篇主報告。材料雖然橫跨術語庫、投影管線、流程分類與契約排序，但它們不是平行主題，而是同一套生命週期治理的不同關節：候選值如何進入、如何暫存、如何判斷成熟、如何回貼、如何剝除、如何分類，以及如何避免把不成熟的形狀誤升格為共享真相。

本次保留為主報告內部分工段落的子題：

- 術語污染：作為生成式候選值進入永久層的風險模型。
- 精確性：作為延後命名與事後策展的理由。
- 可逆投影：作為低成本回滾與全域重貼的工程前提。
- 對稱剝除：作為冪等重推導是否可信的驗證點。
- 角色判定：作為避免外形、成員資格與語法類別誤導管線的通則。
- 知識歸屬：作為避免流程或框架佔有術語本體分類的判準。
- 契約優先與時機切分：作為術語制度演進與能力擴充的排序規則。

移出本系列的部分不是刪除，而是因為它們回答不同層級的治理問題：

| 去向 | 移出理由 |
| :--- | :--- |
| 語意污染與反向治理 | 歷史噪音、命名污染、上下文污染與反向指引是輸入材料如何污染模型注意力的問題；本系列只處理污染進入術語生命週期後如何避免永久化。 |
| 架構約束與決定性管線 | 決定性 pipeline、SSOT 拆分與 extension point 是更廣的系統架構問題；本系列只取用其中與穩定鍵、剝除、重貼相關的投影管線。 |
| 規格驅動開發與棕地治理 | proposal、delta spec、living spec 與流程排序可支撐契約成熟，但完整 SDD / OpenSpec 採用策略不是本系列主題。 |
| 信任邊界與驗證瓶頸 | 自洽、正確、可信的差異是共用前提；本系列把它落在術語可信度，不展開一般 AI code review 或外部裁決架構。 |

## 生成式展開去向

| 展開類型 | 去向 | 理由 |
| :--- | :--- | :--- |
| 拆分 | 本次不拆分 | 各槽位都依賴「延後策展必須可逆」這個共同前提。拆分會使污染模型、投影機制與角色治理變成孤立規則，削弱因果鏈。 |
| 潛在深化 | 本次展開 | 術語生命週期、可逆投影最小模型、對稱剝除、角色/歸屬/時機判準與不適用邊界都在主報告中展開為自包含段落。 |
| 跨篇湧現主題 | 本次展開 | 跨篇合讀後浮現的主題是「術語可信度不是生成結果，而是經由可逆生命週期治理授權後的狀態」；主報告以此作為總論證。 |
