## 背景

探討 AI agent 的接龍狀態機本質如何使傳統代碼品質實踐成為系統性風險來源，並提出代碼層與治理層的雙軌回應。

## 閱讀順序

1. **接龍狀態機的因果斷裂** `Analytical Essay` — 建立 agent 的運算本質和因果連續性的理論框架
   ↓ 理論框架確立後，展開具體的代碼風險表現
2. **代碼整潔度的隱性危害** `Analytical Essay` — 從語意稀釋到設計模式到系統性污染的風險升級鏈
   ↓ 風險識別完成後，提出回應方案
3. **局部完備性** `Analytical Essay` — 約束集與治理防線的雙層回應

## 跨報告連結

- Report 1 結論 ←→ Report 2 引言（causal: 「存在 = token 中可見」命題驅動所有風險向量的識別框架）
- Report 2 反思（系統性崩潰） → Report 3 分析（約束集）（causal: 三層風險模型驅動約束集的設計優先順序）
- Report 1 分析（因果斷裂光譜） ←→ Report 3 反思（治理防護）（refinement: 「錯誤存在」型斷裂在治理層具體化為溯源標記和提升閘門）
