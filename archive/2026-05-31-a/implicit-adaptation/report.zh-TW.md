## Introduction

在長期的 AI 協作中，操作者會自發演化出沒有名字的能力。其中一種可以稱為「設問式操作」：在每次向 Agent 提問之前，先在腦中模擬 Agent 可能的回應，再根據這個預測來校準問題的措辭、範圍和結構，確保 session context 沿著最小必要的方向展開。

這不是任何教材教的技巧。它不在任何 prompt engineering 指南中，不在任何 AI 協作的最佳實踐清單上。它是操作者在數百次互動中，透過觀察「什麼樣的提問方式產生什麼樣的回應品質」，逐漸內化出來的行為模式。操作者自己可能也說不清楚他在做什麼——他只知道某些問法「感覺更有效」，而這個「感覺」就是內化後的判斷力在運作。

在 AI 協作的實踐中，一個反覆出現的困境是：把判斷力寫成規則讓 Agent 執行，效果會隨著規則的精細化而先升後降；用更多外化的文件和模板來管理團隊的產出品質，最終只提升了合規的外觀而非溝通的實質。外化策略有結構性的天花板——文字介質在編碼和解碼的雙重環節都有不可消除的損耗。如果向外有上限，那麼正途應該是向內而不是向外。本文探討這個「向內」的路徑是什麼，它為什麼有效，以及它為什麼抵抗外化。

## Analysis

### 觀念化能力：Katz 的第三種管理技能

Robert Katz 在 1955 年提出管理者的三種核心技能：技術技能（technical skill）、人際技能（human skill）、觀念化能力（conceptual skill）。技術技能是操作工具的能力——知道語法、指令、功能。人際技能是協調人的能力——溝通、說服、團隊合作。觀念化能力是將複雜情境抽象為可操作概念的能力——看見系統的全貌，理解部分與整體的關係，在不完整的資訊中做出判斷。

Katz 觀察到一個規律：層級越低的管理者越依賴技術技能，層級越高的管理者越依賴觀念化能力。這不是因為高層不需要技術，而是因為他們面對的問題無法靠技術技能解決——那些問題的特徵是情境獨特、資訊不完整、沒有標準答案。

設問式操作正是觀念化能力在 AI 協作中的展現。它不是技術技能——不是「知道 Claude 有哪些參數可以調」。它是一種建模能力：在腦中建構「Agent 會怎麼處理這段輸入」的心智模型，用這個模型來預測結果，再根據預測調整輸入。這個過程的每一步都依賴即時的情境判斷——沒有兩次提問的最佳策略是完全相同的，因為 context window 的狀態每次都不同。

### 蘇格拉底的實踐

蘇格拉底不寫書。在雅典的廣場上，他的方法不是把知識寫下來交給別人閱讀，而是透過提問引導對話者自己走到理解的終點。他問的不是「答案是什麼」，而是「你怎麼知道你知道的是對的」——每一個問題都是根據對話者前一個回答即時校準的。

在《費德魯斯篇》中，蘇格拉底對書寫提出了一個直覺上令人不適的批評：文字給人知識的外觀，卻不給人真正的理解。讀過一段文字的人會覺得自己懂了，但當情境改變、需要應用這個知識時，他沒有能力做出調整——因為他得到的是結論，不是產生結論的推理過程。只有透過對話中的反覆詰問，理解才能真正在人的內部生成。

這個兩千四百年前的洞見與 AI 協作中的外化悖論精確對應。Skill 定義就是「寫下來的知識」——它把判斷力的結論固化為規則，交給 Agent「閱讀」。Agent 照規則執行時看起來像是「理解了」，但當情境偏離規則預設的場景時，它沒有能力調整——因為它得到的是結論，不是產生結論的判斷過程。而設問式操作就是蘇格拉底的方法——不把答案寫下來，而是透過即時的提問引導 Agent 自己走到正確的地方。

### 為什麼觀念化能力抵抗外化

把設問式操作寫成規則會是什麼樣子？大概是這樣的：「在提問前，先預測 Agent 的可能回應；如果預測的回應會展開不必要的 context，則調整問題措辭以限縮展開範圍。」

這條規則在邏輯上是正確的。但它完全無用。因為它的每一個動詞——「預測」「判斷什麼是不必要的」「調整」——都依賴即時的情境判斷，而情境是無限的。規則沒有告訴你怎麼預測、怎麼判斷、怎麼調整，因為這些「怎麼」本身就是觀念化能力的運作，不能被進一步分解為有限的指令集。

這就是外化的根本限制：規則只能捕捉判斷的結構（「先預測，再調整」），不能捕捉判斷的內容（「此刻應該預測什麼、調整什麼」）。結構可以外化，內容不能。而觀念化能力的價值恰恰在於它提供的是內容——是在具體情境中做出具體判斷的能力，不是一個可以機械式遵循的流程。

## Reflection

### 外化是對內化失敗的代償

回看 AI 協作中常見的品質問題，一個統一的解釋浮現。團隊中 commit log 品質偏差的根因，不是操作者缺少模板或指南，而是他們還沒有發展出觀念化能力——還不能在腦中建構「這段 commit message 會被怎麼理解」的模型。Skill 精細化後效果反降的根因，是作者試圖把自己的觀念化能力編碼成規則，讓不具備這種能力的人也能「照規則操作」。

外化的衝動來自一個善意的出發點：我有一種有效的判斷方式，我想讓其他人也能用。但觀念化能力的特性使得這個意圖注定落空——它依賴即時情境、不能被分解為有限指令、而且傳遞它的介質本身有損。外化不是解決能力落差的方案，它是承認「我無法讓他們發展出這種能力」之後的退而求其次。

### 內化的路徑

如果外化行不通，內化怎麼發生？回到設問式操作的習得過程，可以辨識出四個階段：

第一階段是無意識的無能。操作者提問時不覺得問法會影響結果。他問「幫我寫一個 function 來處理 X」，得到一個堪用但不夠好的回應，認為這就是 Agent 的能力上限。他不知道自己的問題措辭已經限定了回應的品質。

第二階段是有意識的無能。操作者開始注意到某些互動的效果明顯更好，但說不出差異在哪裡。他可能觀察到同事用更少的來回得到更好的結果，或者自己偶爾「問對了」但無法重現。此時他知道有什麼東西自己不會，但還沒有把它概念化。

第三階段是有意識的能力。操作者開始刻意預測 Agent 的回應，根據預測調整問題。他在提問前會停頓——「如果我這樣問，Agent 可能會展開到不相關的方向，我應該先限定範圍。」這個過程是費力的、刻意的，每一次校準都需要有意識的思考。

第四階段是無意識的能力。校準變成了直覺。操作者不再刻意停頓——他的問題「自然地」就是校準過的。設問式操作成為他的預設行為模式，就像熟練的駕駛者不再刻意想「先看後視鏡再打方向燈」。

這個四階段的過程無法被跳過或壓縮到零。但它可以被支持。最有效的支持不是培訓（培訓傳遞的是技術技能），而是創造讓人反覆經歷第二階段覺察時刻的條件。具體來說：讓操作者接觸到足夠多的差異——如果他能看到自己的互動和高品質互動的具體差異，並且理解差異的來源不是格式而是思維方式，他就進入了觀念化的過程。品質偏差在這個視角下不只是需要修正的問題，它本身就是學習素材。

同樣重要的是避免支持的反面。過度依賴外化規則會抑制內化——當操作者被告知「照模板填」，他就跳過了自己建構心智模型的過程。模板提供了正確答案的外形，但剝奪了產生正確答案的推理練習。這和蘇格拉底對書寫的批評是同一回事：文字給人知識的外觀，卻延遲了真正理解的生成。

## Conclusion

隱性適應的正途是內化為觀念化能力，不是外化為規則。這不只是策略選擇，而是由三個結構性條件決定的必然：文字介質在人與 Agent 之間的傳遞有不可消除的雙重損耗；依賴有損介質的管理策略會放大而非修復品質問題；而觀念化能力的運作本質抵抗被介質承載。

外化與內化的分界線，對應的是 Katz 框架中技術技能與觀念化能力的分界線。技術技能——格式、語法、模板、流程——可以被外化為規則，因為它們在不同情境中是穩定的。觀念化能力——預測、建模、校準、即時判斷——抵抗外化，因為它們的運作依賴情境，而情境是無限的。

分辨一個能力屬於哪一側，是 AI 協作治理設計的關鍵判斷。把技術技能外化成規則，是有效的。把觀念化能力外化成規則，不只是無效的——它消耗介質的承載預算、增加規則的交互複雜度、產生合規的假象，同時延遲了真正需要發生的事：人的內化成長。
