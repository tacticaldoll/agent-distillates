# 導讀

**Session**: 2026-05-31-c
**Reports**: 4
**Series**: 驗證瓶頸

## 背景

2026-05-31-b（SDD 治理運營）建立了三層治理防禦——確定性邊界、衝突封存、回饋迴路——並以「最終判斷不能外包給工具，必須由理解治理目的的人來做」作為結論。

本系列是對這個結論的批判性回應。它追問：如果人也有天花板呢？

四篇報告從模型版本遷移（地基在動）出發，經過技能幻覺（人不知道自己不知道）和速度陷阱（產出堆積快過驗證），到拓撲補償（用 agent 審 agent 的可能性與極限）。敘事弧不收束在解法，而是收束在天花板的具體形狀。

## 閱讀順序

1. **地基會動：模型版本遷移的無聲漂移** `Experience Report` — Claude Opus 4.6 → 4.7 → 4.8，底層模型更替是無聲的全局漂移。前序系列的所有防禦都預設地基穩定，模型遷移打破此前提。
   ↓ 偵測漂移依賴人的直覺，但人的直覺基準可靠嗎？
2. **技能幻覺：當 AI 賦能製造能力的錯覺** `Analytical Essay` — 技能幻覺不是能力退化，而是能力從未存在。Skill 堆積文化、拿 agent 分析訓練集外的私有知識——幻覺在組織中自我強化。
   ↓ 能力不足的人面對大量 AI 產出時...
3. **速度陷阱：當生成速度超過驗證容量** `Analytical Essay` — SDD 的多層 artifact 放大了速度不對稱。三層防禦（lint、開源社群、編譯器）只覆蓋結構性錯誤，語義層以人無法消化的速度堆積未驗證債務。
   ↓ 人來不及審，能不能用 agent 審 agent？
4. **拓撲補償：用 Agent 審 Agent 的可能性與天花板** `Analytical Essay` — 1:N 多 agent 交叉 review 補償注意力盲區，但三個天花板：共享知識盲區、速度乘數、仲裁回歸。殘餘面積（業務邏輯、語義一致性）只能由人判斷。

## 跨報告連結

- 1 → 2（causal）：地基在動時，有能力察覺的前提是人真的懂——技能幻覺質疑這一點
- 2 → 3（causal）：能力不足 × 高速產出 = 未驗證債務堆積
- 3 → 4（causal）：人來不及審 → 嘗試用 agent 審 agent → 有效但有天花板

## 與相鄰系列的關係

- **前序** 2026-05-31-b（SDD 治理運營）：建立治理防禦並以「人做最終判斷」為結論。本系列質疑此結論的三個前提——地基穩定（Report 1 打破）、人有判斷力（Report 2 質疑）、人來得及（Report 3 否定）。
- **前前序** 2026-05-31-a（人機共演化）：揭示介質失真與外化天花板。三個系列構成完整的批判鏈：外化有天花板 → 治理有天花板 → 人也有天花板。
